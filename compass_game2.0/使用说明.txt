compass_game 更新日志汇总（1.0 → 2.0）

1.0 基础版

800×600 窗口，四种工具切换（空 / 点 / 线 / 圆）
鼠标点击绘制，实时预览线 / 圆
键盘数字键切换工具

1.1 交点计算

新增 geometry.py工具包
实现三大交点算法：线线、线圆、圆圆
绘制后自动计算所有交点并加入捕捉点

1.2 交互增强

交点捕捉：点击自动吸附到 10 像素内最近点
Ctrl+Z 撤销：基于操作历史，撤销后重算所有交点
直线延长显示：原始线段黑色粗线，延长部分浅灰细线

1.3 关卡与评分

步数 / 元素数统计（自定义评分体系，非 Euclidea E/L）
共线检测：重复直线不计入步数
第一关：作三角形
过关界面 + S/A/B/C/D 评级
模块拆分：geometry /levels/scoring /ui

1.4 关卡链与工具

操作日志系统（logger.py，三级日志，毫秒级时间戳）
六关完整关卡链：作三角形 → 等边三角形 → 60° 角 → 垂直平分线 → 作中点 → 正方形内切圆
垂直平分线工具（编号 4）
关卡切换：A 上一关 / D 下一关（需通关解锁）
圆的重复检测

1.5 存档与防护

评级存档：scores.dat，Base64 编码 + MD5 校验防篡改
进度存档 / 读档：F1 存档 / F2 读档，多存档位
工具解锁机制：通过第四关后解锁垂直平分线工具
误操作防护：线 / 圆工具两点距离过近不绘制不计步
打包 EXE 路径修复（兼容 onefile 模式）

2.0 UI 美化与跨平台

窗口加高至 800×700，新增底部工具栏（点击按钮切换工具）
工具解锁状态可视化（未解锁置灰）
字体跨平台（Windows / Mac / Linux 自动适配）
网页版支持（Pygbag 打包，浏览器即开即玩）
APP 版支持（PyInstaller 打包 Windows exe）
撤销后预置点丢失修复
工具解锁与进度存档绑定（新开档默认锁定）
