compass_game 2.0 更新日志

新功能

底部工具栏

窗口加高至 800×700，底部新增工具栏
五个工具按钮：空 / 点 / 线 / 圆 / 垂直平分线
当前工具高亮显示，未解锁工具置灰
点击按钮切换工具，键盘数字键仍可使用（2.1 起将禁用）

跨平台支持

网页版：Pygbag 打包，浏览器即开即玩，支持 Windows / Mac / Linux / 安卓
APP 版：PyInstaller 打包 Windows exe
网页版已部署至 Netlify，分享网址即可游玩，无需下载安装

字体跨平台

自动识别操作系统，加载对应中文字体
Windows：微软雅黑 / Mac：苹方 / Linux：文泉驿微米黑
网页版：加载项目内嵌字体文件

修复了已知问题

技术细节

主循环改为 async 异步模式，兼容 Pygbag 网页环境
新增环境判断（网页版 / 本地版），自动适配字体和存档方式
存档文件路径修复，兼容打包后 onefile 模式
