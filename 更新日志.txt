# Compass Game 1.1 更新日志

发布日期：2026-08-17
版本：1.1 — "交点觉醒"

新增功能

- 自动交点计算：画线、画圆后自动与画布上所有已有元素求交，交点处自动生成蓝点
  - 线与线相交 → 1 个交点
  - 线与圆相交 → 0/1/2 个交点
  - 圆与圆相交 → 0/1/2 个交点
- 交点去重：新交点与已有点距离小于 3 像素时不重复添加，避免重叠
- geometry模块独立：所有几何计算函数拆分到 `geometry.py`，主程序更清爽

修复了已知问题

操作说明

- 按 `0` 空工具 / `1` 点 / `2` 线 / `3` 圆
- 线和圆需要点击两次（起点 + 终点 / 圆心 + 圆上点）
- 选起点后移动鼠标有红色预览
- `ESC` 取消当前选择

1.2 预告

- 交点可被工具捕捉（点击时吸附到最近的点）
- 操作历史与撤销（Ctrl+Z）
- 直接画出直线
- E/L 步数统计
- 关卡系统（第一关：作中点）
- 星级评分
